01 — Summary

I'm a Full-Stack Engineer based in Powell, Ohio, currently building production features at Ocean Blue Solutions Inc. Over 3+ years in industry I've owned features end-to-end — designing React + TypeScript front-ends, writing Node.js/Express and Python/FastAPI REST APIs, modeling PostgreSQL and DynamoDB schemas, and deploying to AWS through GitHub Actions pipelines.

My background combines a Master's in Computer Science from Kennesaw State University with hands-on experience at companies ranging from a large enterprise consultancy (Accenture) to focused product teams (HorizonIT, Ocean Blue Solutions). I'm AWS Certified in Machine Learning — Specialty, which gives me an ML-aware perspective on full-stack work, especially when integrating data services and intelligent features into web applications.

What I care about: accessible, performant interfaces; clean API contracts that are easy to consume; databases that scale predictably; and CI/CD that catches problems before they reach production. I write tests, instrument what I ship, and document my work so teammates can pick it up without friction.
