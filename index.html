04 — How I work

Four habits. Boring on paper, lethal in practice.

/01

Ship fast, fix forward.

Working software beats elegant slides. Merge today, polish Monday.

/02

Read the codebase first.

Follow conventions. New code should look like it was always there.

/03

Talk to the user.

Specs lie, users don't. Five real minutes > an hour of speculation.

/04

Use AI as a tool, not a crutch.

Claude compresses my output. It doesn't think for me. Every line ships through my brain.
